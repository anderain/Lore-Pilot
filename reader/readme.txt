Target: Palm OS 2.0 / Pilot Professional, 68000, single segment, no floating
point, runtime PalmOSRuntime_2i_A5.lib.

The resource file now uses only 2.0-safe objects: a plain ICON and SMALLICON
("icon-lg-1.bmp" and "icon-sm-1.bmp"), no icon families, no menus, no Graffiti
state indicator, no NOSAVEBEHIND.  The other icon bitmaps are kept for a future
3.5+/high-density build but are not referenced by the .rcp.

GB2312 12x12; Options > Refresh List / About.
